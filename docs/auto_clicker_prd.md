# 自动点击助手 PRD 文档

## 1. 产品概述

### 1.1 产品名称

自动点击助手 (Auto Clicker Assistant)

### 1.2 产品定位

一款基于 Tauri 开发的桌面应用，用于在指定区域内自动执行鼠标点击操作，主要用于需要重复点击列表项的场景。

### 1.3 目标用户

- 需要频繁切换代理服务器的用户
- 需要定期刷新列表项状态的用户
- 需要进行重复性点击操作的测试人员

### 1.4 核心价值

- 解放双手，自动完成重复点击任务
- 精确控制点击频率和时长
- 提供可视化操作界面，降低使用门槛

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 区域定位功能

**功能描述：**
用户可以通过图形界面标记需要自动点击的列表区域。

**交互流程：**

1. 用户在目标软件中选择并展开某个地区的服务器列表
2. 在本应用中输入地区名称（如"上海"、"云南"）
3. 点击"开始定位列表区域"按钮
4. 按提示将鼠标移动到列表左上角，点击"捕获左上角坐标"
5. 按提示将鼠标移动到列表右下角，点击"捕获右下角坐标并完成"
6. 系统自动计算并显示区域信息

**输出结果：**

- 显示区域坐标范围
- 显示区域尺寸（宽 × 高）
- 预估列表项数量

#### 2.1.2 参数配置功能

**功能描述：**
用户可以自定义点击行为的参数。

**可配置参数：**

- **点击间隔**：1-1440 分钟，默认 30 分钟
- **滚动列表**：开关控制，默认开启
- **滚动间隔**：3-20 次点击，默认 5 次（仅当滚动列表开启时可用）

**界面显示：**

- 实时显示预计点击次数
- 参数输入时进行有效性校验
- 滚动功能通过切换开关控制
- 显示滚动间隔的说明提示

#### 2.1.3 自动点击功能

**功能描述：**
在指定区域内随机选择列表项进行点击，支持滚动列表以访问更多内容。

**点击策略：**

- 根据可见区域高度计算行数（每行约 40 像素）
- 随机选择某一行
- 在该行的中间区域随机生成点击坐标
- X 坐标在列表宽度的中间 2/3 区域随机分布
- Y 坐标在行高的中间 1/3 区域随机分布

**点击执行：**

- 移动鼠标到目标坐标（0.2-0.4 秒动画）
- 短暂停留 0.1 秒
- 执行单击操作
- 等待设定的间隔时间后执行下次点击

**滚动机制：**

- 根据设置的滚动间隔进行触发
- 达到间隔次数后，将鼠标移至列表中心位置
- 随机向上或向下滚动（各 50% 概率）
- 滚动幅度：3 个单位（约 3-4 行）
- 滚动后等待 0.3 秒让列表稳定
- 继续在新的可见区域内点击

**滚动适用场景：**

- 列表项数量超过可见区域
- 需要访问列表中的所有项目
- 列表内容动态刷新

#### 2.1.4 运行控制功能

**功能描述：**
提供完整的启动、停止、重置控制。

**控制按钮：**

- **开始**：启动自动点击任务
- **停止**：立即停止当前任务
- **重置**：清除所有配置和数据，返回初始状态

**自动停止条件：**

- 用户关闭应用程序
- 用户手动点击"停止"按钮

#### 2.1.5 实时监控功能

**功能描述：**
实时显示任务执行状态和统计信息。

**监控指标：**

- 累计点击次数
- 运行状态（运行中/已停止）

**状态更新：**

- 每次点击后更新计数器
- 状态指示灯动画效果

#### 2.1.6 日志记录功能

**功能描述：**
记录每次点击和滚动操作的详细信息。

**日志内容：**

- 点击时间（HH:MM:SS 格式）
- 点击序号（第 N 次点击）
- 点击坐标（X, Y）
- 滚动事件标记（可选）

**日志展示：**

- 最多显示最近 20 条记录
- 自动滚动显示最新记录
- 提供悬停效果增强可读性
- 滚动操作用特殊标识区分

### 2.2 非功能需求

#### 2.2.1 性能要求

- 应用启动时间 < 2 秒
- 坐标捕获响应时间 < 100 毫秒
- 点击操作延迟 < 50 毫秒
- 滚动操作延迟 < 100 毫秒
- 内存占用 < 50 MB
- CPU 占用（空闲时）< 1%
- CPU 占用（运行时）< 5%

#### 2.2.2 稳定性要求

- 长时间运行（2 小时以上）不崩溃
- 支持连续点击 1000+ 次不出错
- 支持连续滚动 100+ 次不出错
- 异常情况下能正常停止任务
- 滚动条位置异常时能自动恢复

#### 2.2.3 兼容性要求

- 支持 Windows 10/11
- 支持 1920×1080 及以上分辨率
- 支持多显示器环境
- 支持不同 DPI 缩放比例（100%-200%）
- 兼容各类滚动条样式（系统原生、自定义）

#### 2.2.4 安全性要求

- 不收集用户数据
- 不进行网络通信
- 本地运行，无需联网

## 3. 技术架构

### 3.1 技术栈选型

**前端：**

- React 18+
- Tailwind CSS
- Lucide React (图标库)

**后端：**

- Rust
- Tauri 2.0+
- Enigo (鼠标控制库 - 支持点击和滚动)
- Rand (随机数生成)
- Chrono (时间处理)

**构建工具：**

- Node.js 18+
- bun
- Rust 2.0+

### 3.2 核心模块

#### 3.2.1 前端模块

- **UI 组件层**：界面渲染和用户交互
- **状态管理层**：应用状态和数据流管理
- **通信层**：与 Rust 后端的 IPC 通信

#### 3.2.2 后端模块

- **鼠标控制模块**：调用系统 API 控制鼠标移动、点击和滚动
- **任务调度模块**：管理点击任务的执行和滚动逻辑
- **事件通知模块**：向前端发送状态更新

### 3.3 通信协议

**前端调用后端：**

```
invoke('get_mouse_position') -> (x: i32, y: i32)
invoke('start_clicking', {
  config: {
    area: {...},
    interval: u64,
    duration: u64,
    enable_scroll: bool,
    scroll_interval: u32
  }
}) -> Result
invoke('stop_clicking') -> Result
invoke('get_status') -> (is_running: bool, count: u32)
```

**后端事件推送：**

```
emit('click-event', { time, x, y, count })
emit('scroll-event', { direction })
emit('auto-stopped', {})
```

### 4.2 交互设计原则

1. **渐进式引导**：通过步骤化流程降低学习成本
2. **即时反馈**：每个操作都有明确的视觉反馈
3. **防误操作**：运行中禁用配置修改，提供二次确认
4. **状态可见**：实时显示运行状态和进度

### 4.3 视觉设计

**色彩方案：**

- 主色调：紫色渐变（#9333EA - #4F46E5）
- 成功状态：绿色（#16A34A）
- 警告状态：黄色（#CA8A04）
- 危险状态：红色（#DC2626）
- 中性色：灰色系列

**图标系统：**

- 使用 Lucide React 图标库
- 统一 18-20px 尺寸
- 保持视觉一致性

- **列表项**：目标软件中的服务器条目
